# Respark – landningssida

Landningssidan för Respark: tidigare kunder får automatiska påminnelser, och
verksamheten ser vilka som kommer tillbaka. Byggd med Next.js, TypeScript,
Tailwind och Motion. Helt statisk – ingen databas och inga miljövariabler.

```bash
npm install
npm run dev     # http://localhost:3000
npm test
npm run build
```

- **Ändra namn, färger, pris, länkar och förbund:** `src/konfig/sajt.ts`
- **Ändra text:** `src/innehall/texter.ts`
- **Teknisk dokumentation och checklista före publicering:** [docs/current_state.md](docs/current_state.md)
